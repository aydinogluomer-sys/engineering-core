# Security policy

Do not include secrets, private source, personal data, or production credentials in an issue or evaluation artifact.

Report suspected vulnerabilities through this repository's [private GitHub security advisory form](https://github.com/aydinogluomer-sys/engineering-core/security/advisories/new). If that channel is unavailable, open a minimal public issue that contains no exploit details and asks the maintainer for a private contact path.

Security reports should identify the affected version or commit, impact, reproduction preconditions, and a sanitized proof. The maintainers will acknowledge and triage reports through GitHub. No response-time SLA is promised.
